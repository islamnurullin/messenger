# Архитектурные решения

Каждая запись фиксирует **одно** решение, причину, по которой оно принято, и его
последствия. Формат — [ADR](https://adr.github.io/): контекст → решение → последствия.

Правило: если решение можно оспорить («почему не наоборот?»), оно заслуживает ADR.
Если нет — хватит комментария в коде.

## Как добавить запись

1. Скопируйте структуру из соседнего файла.
2. Назовите `NNNN-короткое-имя.md`, где `NNNN` — следующий свободный номер.
3. Добавьте строку в таблицу выше.
4. При изменении решения не удаляйте старую запись — поставьте статус «заменено
   записью NNNN» и создайте новую.
