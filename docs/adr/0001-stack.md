# 0001. Выбор стека

**Статус:** принято
**Дата:** 2026-10-22

## Контекст

Задание перечисляет инструменты, но часть из них противоречит друг другу или не
подходит под цель «написать мессенджер за семестр». В задании упомянуты Angular и
Svelte одновременно; мобильная платформа не указана; способ входа не указан.

Нужен стек, который:

- закрывает все четыре платформы (веб, десктоп, Android) без трёх кодовых баз;
- позволяет одному человеку вести проект 12 недель;
- даёт REST + WebSocket, потому что мессенджер без доставки в реальном времени не
  мессенджер.

## Решение

| Слой | Выбор | Почему |
|---|---|---|
| API | Django 5 + DRF | Требование задания; DRF даёт сериализацию и права «из коробки» |
| БД | PostgreSQL 16 | Требование; нужны транзакции и `SELECT ... FOR UPDATE` для счётчика `seq` |
| Realtime | Centrifugo v6 | Требование; снимает с Django держание тысяч WebSocket-соединений |
| Веб | SvelteKit 2 + Svelte 5 | Из двух вариантов задания выбран Svelte: меньше кода на ту же функциональность |
| Десктоп | Electron | Оборачивает уже готовую веб-сборку — третьей кодовой базы не появляется |
| Мобилка | Flutter | Требование задания; Android (заказчик подтвердил, что iOS не нужен) |
| Поиск | Elasticsearch 8 | Требование; индексация вынесена в Celery, чтобы не тормозить отправку |
| Очереди | Celery + Redis | Redis уже есть под Centrifugo, отдельный брокер не нужен |

Angular отклонён: задание допускает Svelte, а держать два фронтенд-фреймворка
одновременно — лишняя работа без выигрыша.

## Последствия

- Плюс: один язык на бэкенде (Python) и один на вебе и десктопе (TypeScript).
- Плюс: Centrifugo масштабируется отдельно от Django.
- Минус: Electron-сборка весит ~150 МБ — для учебного проекта приемлемо.
- Минус: Flutter требует отдельного тулчейна (SDK + Android Studio) — ставится к неделе 8.
